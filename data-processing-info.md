### Legitimate Interest (Article 6/1/f)

### Vital Interest (Article 6/1/d)

- **Technical Data**: 2 years

### Storage Locations
- **Primary**: Firebase (Google Cloud) - secure cloud storage
- **Local**: Encrypted data on your device
- **Backup**: Secure backup systems

## Data Security

### Security Measures
- **Encryption**: All data encrypted in transit and at rest
- **Access Control**: Strict access limitations to personal data
- **Authentication**: Secure user authentication
- **Regular Audits**: Periodic security assessments

### Data Protection
- **Minimization**: Only necessary data is collected
- **Accuracy**: Data accuracy is ensured

## Data Sharing

### With Trusted Contacts
- **Emergency Situations**: Location and status shared only during emergencies
- **Check-in Alerts**: Notifications sent when you miss scheduled check-ins

### With Third Parties
- **Firebase/Google**: Cloud storage and push notification services

- **Right of Restriction (Article 18)**: Restriction of data processing
- **Right of Portability (Article 20)**: Portability of your data
- **Right to Object (Article 21)**: Objection to data processing
- **Right to Withdraw Consent**: Right to withdraw consent
